Maki Ship Anchor Fix 1.1.0
Target: Minecraft 1.21.1 / NeoForge / VS 2.4.12-td.9+66a13242ed (Connector environment)

Design invariants:
- No Foundation/Eureka/bed implementation class or block is hardcoded.
- Riding authority comes from VS ShipMountedToData.
- Sleeping physical authority is the actual post-placement Player position captured in ship-local space.
- The authoritative sleep lifecycle also controls VS native EntityDragger suppression.
- maki-airship-compat's legacy SleepCompat.follow() is cancelled through an optional @Pseudo compatibility mixin,
  so only this mod writes the sleeping player's physical position each tick.
- maki-airship-compat SleepCompat.anchored() is redirected to this authoritative lifecycle so camera/render
  and its legacy drag integration cannot retain a second, stale physical-state model.
- Correctness no longer depends on LivingEntity.tick TAIL mixin priority/order.
- Entity#setPos moves physical position and AABB together on server and clients.
- While sleeping, delta movement and fall distance are reset by the same physical owner.
- The first normal movement packet after dismount/wake realigns vanilla accepted-position baselines.
- Wake placement itself remains in maki-airship-compat; camera/render remain presentation concerns there.
