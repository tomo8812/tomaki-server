# Maki Diorama Sharing 1.1.0

Diorama 0.10.1 / Minecraft 1.21.1 / NeoForge向けのウェイポイント・死亡地点共有MODです。地形共有はDiorama本体が担当し、このMODは共有ウェイポイント・死亡履歴と各プレイヤーの表示件数設定を担当します。

## 地形の配信

サーバーとクライアントの両方に `diorama-0.10.1+neoforge-1.21.1.jar` を配置します。同梱の `config/diorama-server.properties` は以下の設定です。

```properties
share-map=true
share-land=generated
share-kilobytes-per-second=500
web-map=true
```

通常保存された生成済みFULLチャンクを、プレイヤーが訪問していない範囲も含めてDioramaが読み取り、地表の地図用データとして配信します。ChunksmithのCSLODや旧一時キャッシュは読みません。地図のために未生成チャンクを新規生成する機能でもありません。サーバーは読取・パック・送信を行い、地図の描画は各クライアントが行います。

配信枠はクライアントごとに500 KiB/秒です。通常のプレイ用チャンク通信とは別で、人数分の通信・読取負荷が増えます。地図は段階的に補完され、生成や保存が進んだ範囲は以後の更新で反映されます。新規生成・変更を直ちに全域表示する保証はありません。

共有するのは地表です。ネザーなど屋根のあるディメンションと地下の洞窟は、自分が受信した範囲の地図を使用します。村・建物は実際に通常ワールドへ配置・保存されたものが表示されます。地形の配信は村生成の候補判定や配置を進める操作にはなりません。

クライアントではMキーの地図設定のLook（外観）タブにある「ワールドデータから補完」をONにします。英語名は `Fill in from world save` です。既定でONですが既存のOFF設定は維持されます。OFFにすると共有地形による補完を止めます。既に作成・保存された地図は消えません。補完はメインマップが対象で、別に作成したカスタムマップを自動的にすべて埋めるものではありません。

サーバーで地図画像を描画するWeb地図もONです。`http://サーバーのアドレス:8100/` で閲覧できます。外部から見る場合はTCP 8100番への到達が必要です。初回はバックグラウンドで地図画像を生成し、その後は約5分ごとに保存済みチャンクの変更を確認します。`/diorama-web status` で進行状況を確認できます。スマホでプレイ中のPCの地図を見る機能は、クライアント側のOverlaysタブでWeb mapをMy networkにすると使用できます。

## 0.5.0 / 共有MOD 1.0.1からの更新

1. サーバーとクライアントを停止します。
2. 両側の `mods/` から `diorama-0.5.0+neoforge-1.21.1.jar` と `maki-diorama-share-1.0.1.jar` を削除します。旧構成でDioramaをサーバーへ入れていなかった場合は削除不要です。
3. 両側へ `diorama-0.10.1+neoforge-1.21.1.jar` と `maki-diorama-share-1.1.0.jar` を配置します。旧版と重複させないでください。
4. サーバーに同梱の `config/diorama-server.properties` を配置します。既存ファイルがある場合は、独自のマップ制限を維持しつつ上記の共有設定を反映します。
5. 起動し、クライアントの「ワールドデータから補完」がONになっていることを確認します。

船上でのカメラ補正MODを使用しているクライアントは、`maki-diorama-camera-1.0.0.jar` も削除し、同梱の `maki-diorama-camera-1.0.1.jar` へ交換します。サーバーへの導入は不要です。[カメラ補正MODの説明](../maki-diorama-camera/README.md)を参照してください。

ワールドのregion・entities・POI、ChunksmithのLOD、Dioramaの保存済み地図・設定、共有ウェイポイント・死亡履歴の削除や初期化は不要です。地図を初めて新版で開く際は、旧地図形式の補完や追加ズーム段階の作成が発生する場合があります。

## 検証

`gradle check jar` は共有状態の回帰テストに加え、同梱する実際のDiorama JARに対して各Mixinの対象メソッド・コールバック引数・Shadowフィールド・Accessorを照合します。また、Diorama本体の設定ローダーで同梱設定を読み、生成済み地形共有が有効・配信枠500 KiB/秒・Web地図有効であることを確認します。旧版の「クライアント受信済みFULL以外を地図に使わない」制限の検査は撤廃しました。
