# Maki Idle Pregen 1.2.0

無人でChunksmithのタスクが動いている間、Millénaireの村の活動と村人の動作、船の物理時間を停止します。プレイヤー参加・タスク終了時は、このMODによる活動停止を解除し、自身が停止した船の物理を再開します。

- Millénaireの `VillageManager.tick` を停止し、村の活動・成長・改築を進めません。
- `MillVillager.tick` を停止し、村人のAI・移動・作業を進めません。
- 新しい村・孤立建築の候補探索と生成はMillénaire本体の処理を使用します。候補キューや再試行の時計には介入しません。
- Valkyrien Skiesは物理時間を0にし、必要な地形・船体などの状態同期は継続します。
- 村の派生データ初期化・経路グラフ再構築の既存の負荷制限と観測は維持します。

ワールド時刻と通常のシミュレーションは進みます。Minecraftのtick freezeを操作せず、実チャンクの生成・通常保存と、各MODの地形・構造物生成も継続します。

プロジェクト内で `gradle check jar` を実行すると、上流API・Mixin注釈、VS物理停止の所有権・復帰を検証します。実サーバーでの村生成・村人の活動停止・船の物理停止の動作確認は別途必要です。
